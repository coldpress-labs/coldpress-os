## Purpose

Guides human-centered design processes through the five stages of design thinking: Empathize, Define, Ideate, Prototype, and Test. Uses a library of 29 design-thinking methods to facilitate each stage.

## When to Use

- "run design thinking"
- "human-centered design session"
- "empathy mapping"
- When defining a new product or feature from the user's perspective
- When solving complex UX challenges
- When validating assumptions about user needs

## Prerequisites

- A design challenge or problem space to explore
- Data asset: `../../data/methods/design-thinking-methods.csv`

## Process

This skill follows a multi-step guided workflow.

→ See [workflow.md](workflow.md) for the full process.

## Output

A design thinking session document with empathy insights, problem definition, ideation results, prototype concepts, and test plan.
