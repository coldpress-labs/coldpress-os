## Purpose

Applies systematic problem-solving frameworks to break down complex challenges, identify root causes, and design effective solutions. Uses 29 frameworks spanning analytical, creative, and systems-thinking approaches.

## When to Use

- "help me solve this problem"
- "root cause analysis"
- "problem-solving session"
- When facing a complex technical or business challenge
- When initial attempts at solving a problem have failed
- When a problem needs structured decomposition

## Prerequisites

- A clear problem description
- Data asset: `../../data/methods/problem-solving-methods.csv`
