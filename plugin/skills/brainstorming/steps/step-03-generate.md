## Goal

Generate ideas through interactive dialogue using the selected techniques. Target: 100+ ideas before moving to organization.

## Instructions

1. **Present one technique element at a time.** Guide the user through each technique step by step.

2. **Facilitate genuine back-and-forth.** Ask questions, build on responses, push for more.

3. **Apply anti-bias protocol:** Consciously pivot domains every ~10 ideas to prevent anchoring.

4. **Document ideas as they flow.** Number each idea in the output document.

5. **Energy checkpoints every 4-5 exchanges:**
   - "Want to keep going with this technique?"
   - "Ready for a different angle?"
   - "Need a break?"

6. **Support multiple techniques** in one session — when one technique runs dry, transition to the next.

7. **Track progress** toward the 100-idea target.

## User Interaction

Continuous back-and-forth conversation. Present technique prompts, respond to ideas, build on them, push for more.

## Output

Ideas documented in output file, numbered and attributed to techniques.

## Navigation

→ When user signals "enough" or 100+ ideas reached, proceed to [step-04-organize.md](step-04-organize.md)
