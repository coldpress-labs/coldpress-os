## Goal

Transform raw ideas into organized, actionable output.

## Instructions

1. **Identify themes.** Cluster all ideas into 5-8 natural themes.
2. **Prioritize.** Within each theme, rank ideas by impact and feasibility.
3. **Select top ideas.** Surface the 5-10 highest-potential ideas across all themes.
4. **Action planning.** For the top ideas, define next steps.
5. **Write final session document** with all ideas, themes, priorities, and actions.
6. **Present session summary** to user.

## User Interaction

Present themed clusters and ask user to validate/adjust priorities.

## Output

Complete brainstorming session document. Workflow complete.
