## Purpose

Designs and builds a complete Convex-powered feature component — from schema definition through backend functions to frontend integration. Ensures proper Convex patterns including real-time subscriptions, optimistic updates, and proper validator usage.

## When to Use

- "build a Convex component"
- "create feature with Convex"
- "add a new table and functions"
- When building a new feature that needs Convex backend + frontend

## Prerequisites

- Convex project initialized
- Existing schema (will be extended)
