## Goal

Design the skill before writing it.

## Instructions

1. **Define purpose** — What does this skill do? (2-3 sentences)
2. **Select type** — simple, workflow, or reference?
3. **Define inputs** — What does it need to run?
4. **Define outputs** — What does it produce?
5. **Select category** — reviews, testing, creative, utilities, ops, meta, stack-packs
6. **Assign agent** — Which agent persona owns this skill?
7. **Map to lifecycle phases** — When is this skill used?
8. **If workflow:** Outline the steps at a high level.

## Output

Skill design in frontmatter. `step_1_complete: true`
