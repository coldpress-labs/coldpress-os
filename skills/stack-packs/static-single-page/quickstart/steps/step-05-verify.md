## Goal

Verify the Astro project starts, builds, and has the expected baseline files in place.

## Instructions

1. Start the dev server:
   ```bash
   pnpm dev
   ```
   Confirm it starts on `localhost:4321` (Astro default) without errors.

2. Run the production build:
   ```bash
   pnpm build
   ```
   Confirm it exits with code 0.

3. Verify baseline files in `dist/` (post-build):
   - `dist/llms.txt` — LLM access policy
   - `dist/robots.txt` — robots
   - `dist/sitemap-index.xml` — sitemap (generated by plugin)

4. Check TypeScript:
   ```bash
   pnpm exec tsc --noEmit
   ```
   Should pass with no errors.

5. Report to Butler: "env-provision complete — static-single-page pack scaffolded. Dev server ✅, build ✅, baselines ✅."

## Output

- Project passes `pnpm dev` and `pnpm build`
- All baseline files confirmed in place
- TypeScript strict mode passing
