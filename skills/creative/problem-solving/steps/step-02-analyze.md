## Goal

Dig past symptoms to find the true root causes.

## Instructions

1. **Select frameworks** from data asset based on problem type:
   - Technical → 5 Whys, Fishbone Diagram, Fault Tree
   - Systemic → Systems Thinking, Causal Loop, Constraint Analysis
   - Strategic → SWOT, Porter's Five Forces, First Principles
2. **Apply 1-2 frameworks** interactively with the user.
3. **Document root causes** with evidence and confidence level.
