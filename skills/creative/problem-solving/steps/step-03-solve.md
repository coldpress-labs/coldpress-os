## Goal

Generate diverse solutions that address root causes, then select the best.

## Instructions

1. **Generate 3-5 solution options** addressing the root causes.
2. **Evaluate each** against criteria: effectiveness, feasibility, cost, risk, timeline.
3. **Rank solutions** and present trade-offs.
4. **User selects** the preferred solution.

## User Interaction

Present solution options with trade-off analysis. Ask user to select.

## Output

Solutions evaluated, one selected. `step_3_complete: true`
