# `_input/assets/`

**Purpose:** Client-provided visual and brand material.

Put things like:

- Logos (SVG, PNG, favicon sources)
- Brand guidelines (PDF, Figma exports)
- Design tokens (colour palettes, type scales, spacing)
- Images, icons, illustrations
- Fonts (licensed webfonts, WOFF/WOFF2)

Butler reads this folder during Phase 1 `intake` to understand the project's visual identity. Files here feed the graph index and are referenced by later phases (UX design, implementation) when visuals matter.

**Distinct from:**
- `raw/` — unstructured written input (briefs, AI conversation exports)
- `reference/` — optional inspiration (screenshots, links for look-and-feel)
- `vendor/` — third-party technical docs
- `legacy/` — prior attempts, deprecated specs
