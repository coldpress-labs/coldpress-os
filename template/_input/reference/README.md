# `_input/reference/`

**Purpose:** Optional inspiration and background reading.

Put things like:

- Screenshots of sites you like the feel of
- Articles or blog posts that shaped your thinking
- Competitor product pages
- Academic papers, industry reports
- URLs — just paste them anywhere in a text file; Butler's `intake` step will offer to auto-fetch them into this folder as markdown

Butler reads this during Phase 1 `intake` but treats it as softer signal than `raw/` or `vendor/`. Ideas here flavour the later phases but don't bind decisions.

**Distinct from:**
- `raw/` — the project's own starting material
- `vendor/` — *required* third-party integration docs
- `legacy/` — prior attempts at this same project
- `assets/` — client brand/visual material
