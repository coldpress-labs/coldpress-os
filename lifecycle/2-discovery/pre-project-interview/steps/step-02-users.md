## Goal

Understand the users, their needs, and the value proposition.

## Instructions

1. **Identify user types:**
   - Who are the primary users?
   - Are there secondary users (admins, moderators, etc.)?
   - Any API consumers or integrations?

2. **For each user type:**
   - What's their main goal when using this?
   - What's their biggest pain point today?
   - What would delight them?

3. **Value proposition:**
   - What's the one thing this does better than alternatives?
   - How does the user's life change after using this?

4. **Document findings.**

## User Interaction

Continue conversational interview. Build on the vision context from Step 1.
