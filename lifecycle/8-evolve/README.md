# Phase 8: Evolve

> Learn from what was built, correct course when needed, plan what's next.

## This Phase Is Cyclical

Phase 8 doesn't have a "completion" — it loops back to earlier phases:
- Retrospective insights → inform next sprint planning (Phase 5)
- Course corrections → update PRD or architecture (Phase 4)
- Product evolution → restart from discovery (Phase 2)
- Documentation → capture state for future reference
